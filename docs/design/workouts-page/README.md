# Workouts and Account pages

- Workouts: title + person icon (Account), Back to ride + Sync, last synced time, current workout
  with "Remove workout", this week grouped by day. Cards: name, small workout profile, time and date.
  Picking a workout goes straight back to the ride screen. Never auto-picks.
- Syncs through the Karoo (Wi-Fi or phone). Without both: "Enable Wi-Fi to sync" + Turn on Wi-Fi,
  and it syncs by itself once Wi-Fi connects. The last synced week shows offline.
- Account: back arrow, title below, athlete ID + API key (masked), Save at the bottom.
