# Watts range modes

Tap the watts to cycle: **plain → coloured number → coloured background → both**. Remembered between rides.

- Blue below the target range, green in it, red above. The range is the interval's own range from
  intervals.icu (±2.5% by default), ±3% if it has none. Uses 3 s power.
- Coloured background: tint from the top of the field (fades in under Karoo's status bar) down to
  between the tiles and the Next up box, where it fades out. Lap avg / Target tiles are tonal
  (see-through) so the tint shows through.
- Light tints: 48% of the colour over white (black text ≥ 10:1). Dark tints: 38% over black
  (white text ≥ 12:1).
- No colour while paused, after the workout ends, or without power / target.
