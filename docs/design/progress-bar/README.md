# Tonal progress bar

The unfilled part of the interval bar uses the same tonal wash as the Lap avg / Target tiles
(`tile_tonal`) instead of solid grey, so it takes the watts range tint behind it. Only the interval
bar changed; the ⏮ button and the free-ride divider keep the grey `track` colour.
See `tonal-track.html`.

`device/`: 01 below the range (blue tint), 02 in the range (green tint). Light mode only so far.
